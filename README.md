# PICSY Simulator

PICSY（Propagational Investment Currency System：伝播的投資貨幣）の仕組みをブラウザ上で体験できるシミュレーターです。

評価行列（誰が誰にどれだけ価値を感じているか）をもとにして個人の「貢献度」を計算し、それに応じた独自の経済圏がどのように回っていくのかをシミュレーションすることができます。

## アクセス方法

以下のURLをクリックするだけで、特別な設定などは不要ですぐにブラウザ上でシミュレーターを利用できます。

## 基礎概念と操作フロー

シミュレーターを開いたら、以下の順番で操作していくことで PICSY の基本的な仕組みを体験できます。

### 1. メンバーの確認・追加・削除
まずは左側のパネルで現在のネットワーク参加者（メンバー）を確認します。最初は代表的な4人が設定されていますが、「メンバー追加」の入力欄から好きなだけ人を増やすことができますし、不要な場合は「メンバー削除」から退出させることができます。

右上の「総人口」に現在のコミュニティの人数が表示されています。

### 2. 手動取引 (Manual Transaction) でお金を払う
誰かが別の誰かからサービスや価値を受け取り、お金（購買力：P）を支払うプロセスです。
- 右側の操作パネルにある「送信者 (お金を払う人)」と「受信者 (お金をもらう人)」を選び、金額をスライダーで設定します。
- 取引を確定すると、送信者から受信者へお金（P）が移動します。
- 同時に、**お金を支払ったという行為が「受信者から送信者に対する評価（感謝の証）」として評価行列の表に記録されます。** これがPICSYの最も大きな特徴です。

### 3. 貢献度の再計算 (Recalculate C)
しばらく取引を繰り返すと、評価行列の表にたくさんの数字が蓄積されていきます。
- 左側の表の右上にある「貢献度(C)を再計算する」ボタンを押してください。
- するとシステムがネットワーク全体の評価の偏りを複雑な計算（独自のPageRankアルゴリズム）で分析し、一人ひとりにとって今の社会に対する本当の「貢献度 (Contrib：C)」を算出し直します。

### 4. 自然回収 (Recovery System) で時間を進める
お金が一部の場所に偏ったままにならないよう、定期的にある程度の割合を回収して皆に分配し直す仕組み（ゲゼル通貨ベースの減価）です。
- 右側の「自然回収」パネルで減価率（γ）を設定し、「時間を進める」ボタンを押します。
- すると、全メンバーの現在の所持金（P）から設定した割合分が回収されます。
- 回収されたお金は、**先ほど計算した各個人の「貢献度(C)」の高さに応じて再分配**されます。つまり、社会から多くの評価を集めている人ほど、時間が経つにつれて新たなお金が流れ込んでくるようになります。

### 5. 個人ログ・システムログの確認
- まんなかの下にある「システムログ」では、いつ誰が取引をしたのか、いつ再計算が行われたのかなどの全体的な履歴を見ることができます。
- 右下の「個人ログ」で特定の人を選ぶと、**「これまでに誰がお金を払って評価してくれたか（自分との取引実績がある人は誰か）」** の累計を一目で確認できます。
