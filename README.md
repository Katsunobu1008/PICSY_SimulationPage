# PICSY Simulator

「PICSY（伝播的投資貨幣）」の取引シミュレーションを視覚化し、実際の取引イメージをつかむためのウェブページです。
誰が誰にどのような評価（取引）をしたかに基づいて、各個人の「貢献度」を計算し、社会全体のお金がどう循環していくかをブラウザ上で直感的にシミュレーションできます。

## 🌐 アクセス方法
以下のURLをクリックするだけで、特別な設定などは一切不要で、すぐにブラウザ上で利用できます。

## 📖 遊び方と基本の操作フロー

シミュレーターを開いたら、以下の順番で操作していくことでPICSYの基本的な仕組みを体験できます。

### 1. メンバーの確認・追加・削除
まずは左側のパネルで現在のネットワーク参加者（メンバー）を確認します。
最初は代表的なメンバーが設定されていますが、「＋ メンバー追加」の入力欄から好きなだけ人を増やすことができます。

### 2. 手動取引 (Execute Transaction) でお金を払う
「誰かから価値を受け取り、お金（購買力：P）を支払う」プロセスです。
- 右側の「手動取引」パネルで、「Sender（お金を払う人）」と「Receiver（お金をもらう人）」を選び、金額をスライダーで設定して取引を実行します。
- お金を支払うと、**「受信者から送信者に対する感謝の評価」として表に記録されます。** これがPICSYの最も大きな特徴です。

### 3. 貢献度の再計算 (Recalculate C)
取引を何度か繰り返すと、評価行列の表に数字が蓄積されていきます。
- 左側の表の右上にある「貢献度(C)を再計算する」ボタンを押してください。
- システムが社会全体からの「評価の集まり具合」を計算し、一人ひとりにとっての本当の「貢献度 (C)」を算出し直します。

### 4. 自然回収 (Recovery System) で時間を進める
お金が一部の人だけに偏らないように、定期的に少しずつ回収して皆に分配し直す仕組みです。
- 右側の「自然回収」パネルで減価率（回収する割合）を設定し、「時間を進める」ボタンを押します。
- 全員の現在の所持金（P）から設定した割合が一度回収され、**先ほど（3）で計算した各個人の「貢献度(C)」の高さに応じて再分配**されます。
- これにより、社会からの評価をたくさん集めている人ほど、時間が経つにつれて新たなお金が流れ込んでくるようになります。

### 5. ログの確認
- 画面ひだり下にある「システムログ」では、いつ誰が取引や計算を行ったのかの全体的な履歴を見ることができます。
- 右下の「個人ログ（Member Detail View）」で特定の人を選ぶと、**「これまでに誰がお金を払って評価してくれたか」** の累計を一目で確認できます。
